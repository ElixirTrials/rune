The paper’s goal is to give small language models a new memory substrate for multi-step reasoning: instead of keeping the whole trajectory in the context window, the model re-encodes the current state, action, and feedback into a low-rank adapter at every step, so the “memory” of what happened so far lives in weight space rather than tokens. In that sense, it is a recursive generate-observe-reflect loop where each correction is folded back into the next step, aiming to let the model keep reasoning as long as needed without being bottlenecked by context length, which is especially relevant for iterative tasks like coding and proof-like search.

The rationale is that context windows and retrieval both still force past information to be attended to explicitly, while this method tries to make the trajectory itself become part of the model’s parameters in a reversible way. Implementation logic: At each reasoning step, the hypernetwork reads the full trajectory—every attempt and correction so far—and outputs a LoRA adapter in one forward pass. This adapter is applied to the frozen base model, which generates the next action; the resulting feedback extends the trajectory, the hypernetwork is re-queried to produce an updated adapter, and the cycle repeats. The hypernetwork encodes the trajectory (chunking if it exceeds its context limit), pools the chunks into a fixed-size representation via cross-attention, then projects that representation to per-layer LoRA weights. Because the base model stays frozen and the adapter is reversible, unloading it restores the original model exactly, and per-step cost remains constant regardless of how deep the reasoning chain grows.
